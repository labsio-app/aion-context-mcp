# First session example

After connecting an MCP host, try:

> We are building an AION 2 Global knowledge base. Search what we already know about ILVL versus Combat Power. Keep TW and Global applicability separate. If what you find is only TW evidence, tell me explicitly what would still need validation for Global.

Then:

> I have a YouTube transcript. Record the video as a TW source, extract only durable observations, and save them as separate knowledge items linked to that source. Anything interpretative must be a THEORY, not an OBSERVATION.

Then test contradiction handling:

> Search our current claim about X. I now have a source that contradicts it. Do not overwrite the existing knowledge: record a challenge and explain what would resolve it.
